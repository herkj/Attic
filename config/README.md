# config/

Reserved folder. Nothing in this repo writes here anymore.

User-specific settings and generated taxonomy now live in your **vault**, under `Research/config/`:

- `Research/config/taxonomy/{name}.yaml` - domain taxonomy generated by `/setup-attic` (or hand-written)
- `Research/config/taxonomy/learned.yaml` - taxonomy additions from `/improve`
- `Research/config/learning/` - review journal, examples, preferences, improve history

Those files survive `git pull` because they are outside this repo. This folder is kept only as a placeholder and can be removed.
